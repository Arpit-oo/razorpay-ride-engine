1. Ride-Sharing Matching & Pricing Engine
Core Functional Requirements:
Manage driver/rider locations and statuses.
Implement a basic matching algorithm (nearest driver).
Basic ride booking flow (request, accept, complete).
AI-Assisted (80%):
Implement dynamic surge pricing based on real-time demand/supply, time of day, and predicted future demand.
Develop an intelligent ETA prediction model considering simulated traffic, driver behavior, and route optimization.
Generate optimized routing for shared rides (pooling) considering multiple pickups/drop-offs and minimizing detours.
Implement a driver recommendation system based on past performance, rider ratings, and proximity.
Manual Coding (20%):
Ensure thread-safe updates for driver locations and ride statuses under high concurrency.
Implement robust error handling for payment processing failures and ride cancellations.
Write comprehensive integration tests for the matching, pricing, and pooling algorithms.
